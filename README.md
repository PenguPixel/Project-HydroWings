### Liste Externer Assets:

#### AQUIS - Water Toon Shader 
- Quelle: Unity Asset Store 
- von AureDevGames

Verwendet wurde er für den stylyzed Wasser-Shader auf unserem WaterSurface.

Der Shader wurde von Philipp so modifiziert, dass er seine Origins auf das Objekt bezieht auf den er angewendet wird um das für unser Projekt gewünschte Scroll Verhalten erreichen zu können. 

#### War FX
- Quelle: Unity Asset Store 
- von Jean Moreno

Aus diesem FX Paket haben wir einen Explosions Partikel Effekt für die Explosions der Puffins verwendet.

Der verwendete Partikeleffekt wurde von Philipp so modifiziert, dass er die für uns passende Form und Größe hat sowie die Menge an Partikeln und Dauer angepasst.

#### Sweet LandGUI
- Quelle: Unity Asset Store
- von Persefida

Aus diesem GUI Paket haben wir einiger Buttons für das Pause- und Settingsmenü verwendet.

#### FREE CARTOON PARALLAX 2D BACKGROUNDS
- Quelle: https://craftpix.net/freebies/free-cartoon-parallax-2d-backgrounds/
- Autor unbekannt

Aus dieser Sammlung haben wir zwei Varianten an Hintergründen für die Level- und Bossszenen in unserem Game benutzt.

#### Food Kit

- Quelle: https://kenney.nl/assets/food-kit
- von Kenney

Aus diesem Set haben wir die Süßigkeiten FBX Dateien für unsere Obstacle Prefabs benutzt.
